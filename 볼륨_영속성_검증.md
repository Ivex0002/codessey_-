# Docker 볼륨 영속성 검증

### 로그
```
PS C:\Users\User\Documents\mission1_miniproject_port> docker volume ls
DRIVER    VOLUME NAME
local     my-web-data
PS C:\Users\User\Documents\mission1_miniproject_port> docker volume create my-vol
my-vol
PS C:\Users\User\Documents\mission1_miniproject_port> docker volume ls
DRIVER    VOLUME NAME
local     my-vol
local     my-web-data
PS C:\Users\User\Documents\mission1_miniproject_port> docker run -d --name vol-test -v my-vol:/data ubuntu sleep infinity
21deb48d7a35265cc47714d3fe7707a1ec0deaffc3f1cb410276dba1d4a4d5a2
PS C:\Users\User\Documents\mission1_miniproject_port> docker exec vol-test sh -c "echo 'Volume Test Success!' > /data/test.txt"
PS C:\Users\User\Documents\mission1_miniproject_port> docker rm -f vol-test
vol-test
PS C:\Users\User\Documents\mission1_miniproject_port> docker run --rm -v my-vol:/data ubuntu cat /data/test.txt
Volume Test Success!
```
- `docker volume ls`로 이전 사용자와 이름이 충돌할 가능성을 확인함
- 겹치지 않는 이름인 `my-vol`으로 작성
- 해당 볼륨이 제대로 생성되었음을 확인
- 이전에 제작한 `sleep infinity` 컨테이너와 연결
- 테스트용 문자 입력
- 컨테이너 삭제 후 입력한 문자열이 제대로 있는지 확인(데이터 휘발x)
